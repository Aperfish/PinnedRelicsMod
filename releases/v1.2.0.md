## 关键筹码置顶 1.2.0（预发布）

适用于《吉星派对》的 CesiumLoader 模组。玩家获得名单内筹码后，在左侧对应玩家的星币下方横排显示图片；只显示已持有筹码，不显示名称或数值。

### 本版更新

- 同版本补充：默认置顶名单加入“美工刀-初级”和“美工刀-锋利”，共八种；版本号仍为 1.2.0。

- 改用游戏原生筹码图片和品质底圈，与游戏玩家详情界面使用相同的资源加载方式。
- 不再依赖或附带 Wiki 图片，无需 `assets` 目录，安装包约 36 KB。
- 保留 `PinnedRelicNames` 中文名配置，可添加、删除及调整显示顺序。
- 支持 90 种筹码名称，包括“时间怀表(破碎)”。
- 保留原有位置、图标大小与间距设置，默认图标大小 30、间距 3。
- 保留 1.1.1 的名称目录兼容修复，不再读取 DLL 内嵌资源。

### 安装与更新

1. 下载附件 `PinnedRelicsMod-1.2.0.zip`，在支持 CesiumLoader 的启动器中导入；或退出游戏后，将包内的 `PinnedRelicsMod` 文件夹放入 `AstralParty_ModLoader/mods/`。
2. 更新旧版本时保留自己的 `config.json`；如需新增默认的两种美工刀，请在 `PinnedRelicNames` 末尾追加 `美工刀-初级,美工刀-锋利`。旧版 `assets` 图片不再使用。
3. 启用“关键筹码置顶”，重新启动游戏。

添加筹码示例：在启动器的 `PinnedRelicNames` 字段中填写以下内容，即在原名单后增加“星币锤”：

```text
肾上腺素-高效,磨刀石,友情徽章,安全气囊,紫色飞星,金色飞星,美工刀-初级,美工刀-锋利,星币锤
```

支持逗号、顿号、分号或换行分隔，按填写顺序排列；空字符串可清空显示。完整名称与配置见仓库 README 和《支持的筹码.md》。

### 验证与限制

- 使用 CesiumLoader 3.7.0 SDK 构建，Release 编译 0 警告、0 错误。
- 11 项名称匹配、去重、排序和持有列表检查通过。
- 游戏原生资源的实际显示与清晰度仍需更多对局验证，因此本次标记为 **Pre-release（预发布）**。
- 小尺寸图标的可读性仍受原素材与 UI 缩放影响，不承诺更换资源来源后一定更清晰。
- SDK、游戏程序集、配表原始文件及游戏图片不随模组或源码包分发。
